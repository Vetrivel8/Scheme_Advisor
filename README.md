# 🌐 Smart Scheme Advisor

### 🧠 AI-Inspired Government Scheme Recommendation Platform

> Helping citizens discover the **right government schemes** they are eligible for — instantly and easily.

---

## 🚀 Overview

**Smart Scheme Advisor** is a full-stack web application that recommends government welfare schemes based on user details like:

* 👤 Age
* 💰 Income
* 👨‍🌾 Occupation
* 📍 Location
* ⚧ Gender
* 🏷 Category

The system intelligently matches users with eligible schemes and provides:

* 📋 Required documents
* ✅ Eligibility explanation
* 💬 Chatbot support *(future scope)*
* 📊 Admin analytics dashboard

---

## 🎯 Problem Statement

Many citizens miss government benefits because:

* ❌ Lack of awareness
* ❌ Complex portals
* ❌ Difficult eligibility criteria

This platform solves that problem by providing **personalized recommendations**.
